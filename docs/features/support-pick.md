# 応援ありのスタッフの「施設を選ぶ画面」（supportPick）

2026-11-02 ユーザー指示。穂乃味だけ（機能フラグ `supportPick`。マンテールは `false` で従来どおり）。

## 動き

- 応援あり（`canSupportWork`）のスタッフが、**その日まだどこでも出勤していない**とき、PIN の次に打刻画面ではなく「📍 今日はどこで出勤しますか？」の画面を出す。
- 施設のボタンを全部並べる。**この端末の施設**（施設URLの施設。無ければ所属）を先頭に、色付き・大きめで「この端末の施設」と添えて出す（ユーザー指示 A）。
- 施設を押すと打刻画面へ進む。出勤ボタンの上には選んだ施設を表示し、プルダウンは出さない。「施設を選び直す」で施設を選ぶ画面へ戻れる（ユーザー指示 B）。
- 出勤の記録は従来どおり `selectedWorkFacility` を勤務先（`workFacility`）にする（`doPunch`）。
- 出さない場合: 出勤済みの日（休憩・退勤・施設変更は打刻画面から）／応援なしのスタッフ／承認済み有給の日／打刻完了の表示中。
- 選んだ状態（`workFacilityPicked`）は、ホームへ戻る・打刻後の自動復帰・サンドボックスの出入りで消す（次のスタッフに持ち越さない）。

## 注意

- 当日の打刻をサーバから受け取る前（`recordsReady=false`）は、端末の記録で「未出勤」と判断して施設を選ぶ画面を出すことがある。届いた時点で出勤済みなら、再描画で打刻画面に戻る。
- 施設を選ぶ画面には申請ボタン（時刻修正・有給）を出さない。申請だけしたい日も、施設を押してから打刻画面の申請ボタンを使う。

## 試験

- `node tests/visual/support-pick.js`（Playwright。ネットワークは模擬）
- 機能フラグはクライアント（`TENANT_CONFIGS`）とサーバ（`api/_lib/tenant.js`）で同じ値にする（`node scripts/test-multitenant.js` が照合）。

# 退勤時の賄い確認

2026-10-12 追加（ユーザー指示「賄い登録を退勤時に聞くようにしたい」）。

## 動き

- 「賄い 要」（`mealRequired`）のスタッフが**退勤**を打刻すると、打刻完了の直後に
  「◯月◯日、賄いを食べましたか？」（はい／いいえ）を出す。
- 「はい」→ その日を賄い取得ありにして `tc5_meals/{社員番号}` へ PUT（既存の `mealSaveEntry` と同じ経路・同じ形）。
- 「いいえ」・枠外タップ → 何も書かない。後から打刻画面の賄いカードで修正できる（従来どおり）。
- 実装: `index.html` の `mealAskAfterClockOut(name, ds)`。`_execPunch` の末尾（⑥）から呼ぶ。

## 不変条件（★）

- ★ 聞くのは退勤の**端末保存・画面の打刻済み・送信開始の後**。打刻の条件にしない・await しない（閉じても退勤はそのまま）。
- ★ 賄いデータ未取得（`mealsLoaded` 偽）のときは聞かない（`tc5_meals/{eid}` は丸ごと PUT のため、読めていない状態で書くと他の日が消える）。
- 閲覧用・賄い不要・社員番号なし/不正・編集不可の月・その日が既に取得ありのときは聞かない。
- 回帰テスト: `node scripts/test-meal-clockout.js`（`_execPunch` の結線も検証）。

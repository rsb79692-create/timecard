有給申請マニュアル（申請者向け）
株式会社 穂乃味 2026年6月発行
1. 有給申請とは

タイムカードアプリから、取得したい日の有給休暇を事前に申請する機能です。申請後は管理者が確認し、承認または却下されます。
承認が完了するまでは、有給取得は確定していませんのでご注意ください。

2. 有給申請の流れ
  1. 1
    タイムカード画面を開く ブラウザで会社指定のタイムカード URL にアクセスします。
  2. 2
    自分の名前を選ぶ スタッフ選択画面で自分の名前をタップ・クリックし、PIN を入力してログインします。
  3. 3
    「有給申請」を開く 打刻画面下部の「有給申請」ボタンをタップします。有給申請エリアが展開されます。
  4. 4
    取得したい日付を選ぶ カレンダーまたは日付入力欄で、有給を取得したい日を選択します。
  5. 5
    内容を確認する 選択した日付と残日数が正しいことを確認します。残日数が 0 日の場合は申請できません。
  6. 6
    「申請する」ボタンを押す 確認後、「申請する」ボタンをタップして申請を送信します。画面に「申請中」と表示されれば完了です。
3. 申請後の状態
申請中 管理者が確認前の状態です。まだ有給は確定していません。
承認済み 管理者が承認した状態です。有給が確定し、残日数から差し引かれます。
却下 管理者が申請を却下した状態です。理由を確認し、必要に応じて再申請または管理者へ相談してください。
取消済み 申請が取り消された状態です。残日数は元に戻ります。
4. 注意事項
  • 残日数が足りない場合は申請できません。申請ボタンが非活性になります。残日数は有給申請エリアで確認できます。
  • 承認されるまでは確定ではありません。「申請中」の状態では、まだ有給は取得されていません。
  • 間違えた場合は早めに管理者へ連絡してください。「申請中」の状態であれば取消が可能な場合があります。承認後の取消は管理者対応が必要です。
  • 勤務シフトとの重複に注意してください。有給申請後も、シフト変更は別途担当者に確認・連絡が必要です。
5. よくあるケース
申請したが画面に反映されない
ブラウザを更新（リロード）してください。それでも表示されない場合は、管理者に申請が届いているか確認してください。
間違えて申請した
すぐに管理者へ連絡してください。「申請中」の段階であれば取消できる場合があります。承認済みの場合は管理者による取消が必要です。
残日数が 0 と表示される
付与された有給が 0 日か、すでに全日数を使用・申請済みの状態です。付与状況を管理者に確認してください。

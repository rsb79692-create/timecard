# docs/records — 調査・実測・経緯・完了記録

日付付きの記録（`YYYY-MM-DD-<要旨>.md`）。調査結果、本番の実測値、ベンチマーク、障害の経緯、
撤回した旧記載、完了した作業、トラブルシューティングの記録を置く。import されない。

- ★ secret・token・接続文字列・本番の個人データ（氏名・連絡先・UUID 等）を書かない。誤って書いた場合は、追記の原則より削除を優先する。
- 記録は書き換えずに追記する（当時の事実として残す）。現在の規則は `AGENTS.md`、仕様は `docs/features/` を正とする。
- `AGENTS.md` に「YYYY-MM-DD 実測」「経緯」「撤回」を書き足したくなったら、ここへ書いて参照させる。
